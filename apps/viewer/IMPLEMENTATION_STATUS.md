# Viewer 实现与验收状态

最新需求以 [需求文档](REQUIREMENTS.zh-CN.md) 为准；本文件记录当前纯前端实现与仍有效的验证证据。

## 开发边界

只修改 `apps/viewer/`，允许新增 `packages/viewer-*`。现有 app/package 的源码、配置、API 和根锁文件保持原样。原 Electron 应用继续引用原文件，没有 wrapper 重定向。

Viewer 自有包从提交 `4863835963c99793c47b72473900c483e9fa0c2a` 保存源码快照；已有纯引擎只读复用。计划中的“修改原 app 以共享抽取实现”已废弃。

## 已实现

- 静态页面。主页面读取本地文件或允许跨域的链接，识别格式后用 blob URL 打开预览 iframe。不创建预览会话，不把源文件写到服务器。
- PPT：浏览器 Worker 调用原 `openPptx`、`materializeSlide`、`buildRenderSlide`，再用页面已加载字体测量字宽并回传，最多 6 轮。度量字体随页面发布，不扫描系统字体目录。绘制仍是 Konva；缩略图、翻页、放映、动画、转场、链接和音视频沿用原组件。媒体字节从 pptx 读出。
- PDF：PDF.js 打开 blob URL。文字层、只读表单、链接、已保存批注、缩略图、目录、跳页、缩放、旋转、文档信息和密码读取沿用原层。
- Word：浏览器解析 Worker、分页和只读视图。加密文档在浏览器解密。图片和嵌入字体从文档 zip 读出并变成 blob URL。分栏、页眉页脚、修订、标题和书签沿用原展示。
- Word HTML/MHT altChunk：纯前端不能调用服务端 Chrome，遇到时明确失败，不静默丢掉正文。
- URL 导入：浏览器 fetch。跨域被拒绝时直接提示。支持签名参数和下载文件名；没有扩展名时按内容识别。
- 发布目录是静态站点，包含页面、Worker、打包字体、PDF.js 资源和许可证。开发时 Vite 监听 `0.0.0.0:11001`，可用 `VIEWER_HOST` 限制为本机。
- 链接参数控制文件栏、本地导入、URL 导入、三格式操作栏、导航侧栏和错误显示；`embed=1` 一键隐藏，显式开关覆盖默认值。主页面 `url` 可自动导入文件直链。

## 本轮验证

类型检查和静态站点构建已通过。早前针对 Node 会话、Cookie、磁盘文件和 Chromium altChunk 的回归描述的是已退出预览路径的服务，不能当作当前纯前端的验收证据。

浏览器验证覆盖：同一份业务 PPT 在浏览器内排出 5 页，缩略图和主画布有内容；PDF 表单样本读出页面和正文；Word 简单文档读出标题和段落。跨域链接会提示文件服务器需要允许当前页面访问。

界面专项验证覆盖：三格式工具栏在明暗主题和 375/768/1130/1440 像素宽度下无控件横向溢出；原生页码选择及隐藏搜索的保留逻辑通过阅读回归。PPT 缩略图在 1212×657 视口和占宽滚动条下，无横向溢出、缩略图及边框完整，纵向滚动与选页通过浏览器回归。

显示开关和预览参数由页面自己读取。原先依赖 Node 服务的界面、阅读、URL 和媒体冒烟已随服务源码删除。

阅读回归里关于活动会话跨 TTL 保活的部分对应当时的 Node 会话，当前预览没有这条链路。页数记录是当时 Viewer 的运行结果，不是原 Electron 的 golden 页数。

URL 专项里关于会话所有者、服务器代下载、内网地址开关和临时文件清理的部分，对应当时的 Node 导入。当前 URL 由浏览器 fetch，失败时只在页面提示。

独立产物现在是静态目录。`test:standalone` 确认发布目录含有页面、且不含 Node 服务或 PM2 配置。

媒体播放仍由浏览器解码文档内的音视频。不再由服务端按 Range 提供媒体字节。

这些检查证明应用可运行和核心实现沿用，不等同于复杂文档的完整视觉一致性验收。
