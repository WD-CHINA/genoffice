01

总览架构

三端围绕同一个 /v1 HTTP 契约（packages/parse-contract）协作：Web 静态站可完全本地解析，也可把解析切到服务端；Android 壳把服务端"已解析的模型"整包下载后离线回放给同一份 Web Viewer。

图 1-1 · 三端关系

媒体永远不进 JSON：渲染树里只写 /v1/files/:id/parts/* 引用，浏览器按需 Range 取。

1 GI B 上传 · RSS 103 MB

上传全程流式落盘不缓冲整份，实测 1 GiB 约 867 MB/s，峰值 RSS 仅 103 MB。

256 MI B XML 上限

PPTX 解析限制的是瘦包 XML 体量而非原文件大小，媒体留盘不进解析。

三档解析位置

auto（大于 64 MiB 走服务端）/ local / server，host 文件栏可切换并记忆。

02

Web 端 · 打开文件

入口在 host.tsx：三种来源汇入同一条「大小检查 → 解析位置决策 → iframe 注参」的主线；本地已知扩展名的文件全程不读入内存。

04

PPTX 字宽回传闭环

PPT 换行依赖浏览器实测字宽，这是两端一致性的核心机制：服务端先用启发式度量起步，浏览器加载字体实测后回传，服务端清缓存重排，循环直到无待测量项。首屏、懒加载页、放映预加载后都跑同一循环。

图 4-1 · 测量 → 回传 → 重排循环

极老的嵌入字体可能被 Chromium OTS 拒绝：回退替代字体并输出 warning，不中断流程。

字体请求 23 → 3

按排版实际请求的字体加载，不再默认下载全部 23 个度量字体；字体响应体从约 12.83 MiB 降至 1.65–3.08 MiB。

只重排受影响页

回传只重建依赖这些测量 key 的幻灯片，Worker 只返回变化的页面，主线程合并其余页面。

闭环不可省

省略回传会导致换行与字形位置漂移——这是验收口径，不是性能优化项。

05

服务端 · PPTX 会话流水线与故障隔离

apps/parse-server 用「内容寻址存储 + 瘦包 + 每会话一 worker」接住 1 GiB 级 PPTX；任何单个 job 的超时 / OOM 都被隔离在 worker 内，HTTP 健康检查不受影响。

图 5-1 · 上传到按页取用的完整链路

实测：256 MiB deck（空白页 + 256 MiB stored 媒体）开会在约 22 ms、RSS 增量约 0.5 MiB——媒体从未被解压进内存。

持久化

会话元数据原子写 sessions.json，重启后 model/units 可读、worker 懒重建；可选 MySQL 存元数据，大内容仍留磁盘。

可观测

每请求一行 JSON 日志；/metrics 输出 Prometheus 指标；/v1/health 含 sessions、workers、errors、memory。

删除保护

活跃会话存在时 DELETE /v1/files/:id 返回 409 file_in_use。

07

Android · 离线包下载与回放

移动端不引入任何解析/排版代码：先从解析服务把「已解析的模型 + 媒体 + 字体」整包下载并改写 URL，再由 loopback HTTP 服务按同一契约离线回放，渲染复用 Web Viewer 的客户端排版路径。

图 7-1 · BundleDownloader → LocalAssetServer → WebView

同源设计是关键：页面与 /v1 同 origin，无 CORS、canvas 不被跨域污染，音视频直接播本地缓存文件。

构建链

Web Viewer 以 VIEWER_BASE=/viewer/ 构建后由 Gradle 同步进 APK assets，再 assembleDebug。

联调

adb reverse tcp:8790 tcp:8790 让真机经 USB 访问电脑上的解析服务，intent 传 server/fileId/download。

已知限制

离屏页按当前页 ±1 淘汰，回访需重新拉取；媒体签名默认 12 小时；离线包无空间回收；演示允许明文 HTTP。

08

三端职责分界

解析被拆成五个阶段，只有一部分能搬到服务端——这张表是三端协作的边界合同。

角色负责不负责
浏览器前端渲染、DOM 测量/分页、字体加载、交互、按需取资源、小文件本地解析（含 DOCX 本地预览）大文件整份读入、CPU 密集解析的可靠性
解析服务容器索引、XML → 模型、PPT 版面、缓存、限流与 worker 隔离DOM 分页、最终绘制、字体实测（必须回传浏览器结果）
Android 壳会话下载与 URL 改写、本地回放服务、WebView 生命周期任何解析/排版逻辑（全部复用 Web Viewer）
格式服务端完成阶段说明
PPTXindex · model · layout版面在服务端，字宽必须回传浏览器；1 GiB 主路径
PDF—（无）PDF.js 自绘，服务端只做 Range 内容服务
DOCXindex · modelblock-chunk 会话；1 GiB 全方案（流式 tokenizer + 分页虚拟化）已推迟
