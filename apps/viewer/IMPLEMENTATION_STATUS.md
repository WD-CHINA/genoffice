# Viewer 实现与验收状态

最新需求和文件保留策略以 [需求文档](REQUIREMENTS.zh-CN.md) 为准；本文件记录实现与验证证据。

## 开发边界

只修改 `apps/viewer/`，允许新增 `packages/viewer-*`。现有 app/package 的源码、配置、API 和根锁文件保持原样。原 Electron 应用继续引用原文件，没有 wrapper 重定向。

Viewer 自有包从提交 `4863835963c99793c47b72473900c483e9fa0c2a` 保存源码快照；已有纯引擎只读复用。计划中的“修改原 app 以共享抽取实现”已废弃。

## 已实现

- 一个独立 Node HTTP 服务和 Vite/React app；每次预览使用新 iframe，隔离三种格式的 CSS、FontFace、模块状态及浏览器 Worker。
- 上传类型/大小校验，Cookie 所有者隔离、随机资源 ID、原文件 SHA-256、活动会话续期/失效恢复、空闲 TTL、文件清理、会话关闭及 PPT Worker/ZIP 句柄/解密明文释放。
- PPT：原 `pptx-engine → pptx-render → Konva`；原字体查找/HarfBuzz/嵌入字体、浏览器字体反馈、媒体解码；缩略图、翻页，以及原放映/动画/转场/链接/媒体组件；普通预览点击媒体封面叠加原生 audio/video 控件，沿用原 App 播放器的尺寸、位置和外观。字体反馈具有 revision/batch 校验和并发互斥。普通预览沿用原链接命中算法，支持页码/缩放/适配；私有字体自动重试与重新测量，修复带空格字体 ID 的 URL 编解码。
- PDF：原 PDF.js 配置/资源、可见页面渲染、文本层、表单目录及只读 FormLayer、LinkLayer；原索引搜索/命中矩形高亮/逐项定位、缩略图/书签/标题目录、跳页与当前页追踪、缩放/适配、旋转、已保存 Text 批注正文及回复线程、文档信息/XFA 提示、坏链接兜底、密码回调和 Range 读取。
- Word：原后台解析 Worker、内嵌字体、Tiptap 自定义节点、样式/主题、分阶段内容加载，以及原分页/页眉页脚/脚注尾注/批注/修订展示；接入逐块分栏/宽度/网格/字距/边距/竖排等布局修正，样式提交和字体就绪后生成稳定快照；晚到字体触发原行/页眉缓存失效并重测。新增文字搜索/复制/链接、标题/书签和批注定位、辅助阅读、缩放/跳页/页码追踪、原页色/header phantom、修订模式、原 slimDocx 按需 HTTP 图片、加密 DOCX 密码错误重试。
- Word HTML/MHT altChunk：保留原 html2docx 算法，替换 Electron BrowserDriver 为 Playwright；沿用原 794×1123 / DPR 2 初始环境，单次独立 BrowserContext，最多两个并发转换，取消/超时关闭浏览器。重复打开初始化共用一次解析；转换失败明确报错。
- URL 导入：HTTP/HTTPS 文件直链、签名参数/重定向、响应下载名称及无扩展名格式识别；流式下载共用本地文件/会话/原解析链路；超时/大小/内容校验、取消清理和失效重新下载。默认阻止本机/内网目的地，可信部署可显式开启。
- 前后端依赖边界检查、运行时 manifest/lockfile、独立发布目录及许可证收集。
- 按用户最新要求，PPT/PDF 跳页使用原生 select；PDF/Word 搜索控件隐藏，搜索与高亮代码保留。文件栏及三格式工具栏统一分组、图标、选中/焦点状态、明暗主题与窄屏布局。PPT 缩略图侧栏只纵向滚动并预留滚动条空间。
- 开发前端与生产 Node 默认监听 `0.0.0.0`，支持局域网访问；可用 `VIEWER_HOST` 限制监听地址。启动日志显示局域网 IPv4 地址。Vite 代理保留 Host，且仅匹配 `/api/` 和 `/pdfjs/` 资源，避免将前端 `/api.ts` 模块转发到后端。

## 本轮验证

类型检查、生产构建及 18 项 API/源码回归检查已通过。API/源码回归新增短 TTL 的续期/空闲回收，及原 lazy media 的授权、hash/part 校验、Range、重复内容请求、关闭失效和原文件不变；其余覆盖：原核心绘图、动画、分页及字体查找源码一致性；上传格式和大小；所有者隔离；字节范围和只读原文件；会话删除；PPT fixture 排版和字体反馈冲突；原 Chromium altChunk 转换。

浏览器验证覆盖：业务 PPT 的 5 页、缩略图、翻页、放映方向键和退出；PDF 的原页面、已保存文本/复选框值、只读表单和旋转；Word kitchen-sink 的分页/表格/只读 DOM；HTML altChunk 从 Worker 回退到原转换链路后展示。

界面专项验证覆盖：三格式工具栏在明暗主题和 375/768/1130/1440 像素宽度下无控件横向溢出；原生页码选择及隐藏搜索的保留逻辑通过阅读回归。PPT 缩略图在 1212×657 视口和占宽滚动条下，无横向溢出、缩略图及边框完整，纵向滚动与选页通过浏览器回归。

新增阅读浏览器回归覆盖：真实嵌入字体下载前两次失败后重试成功、测量 pending 清空；PPT 预览元素链接/跳页/缩放；三页 PDF 缩略图、标题目录、搜索数量与高亮、保存的批注作者/正文/回复、信息查看；Word 文字搜索/复制、书签、页色、最终修订显示、密码错误重试、混合不等宽分栏和不同节网格/字距、按需图片解码；仓库 08/21/22 三份多节/分栏语料均稳定为 2 页，已延迟字体并重复打开验证；活动会话跨多个短 TTL 保活和失效重新打开。生成样本及截图在 `test-results/reading`。这些页数是 Viewer 运行结果，不是原 Electron 的 golden 页数。

URL 专项回归验证：重定向签名参数保留、中文下载名、PPT/Word/PDF 格式识别及原字节/hash、会话所有者隔离、HTTP 压缩、无效协议/凭据/分享页/空文件、声明与流式/解压后大小限制、总超时、域名解析后的地址固定/连接回退、客户端取消后的临时文件清理，以及默认内网地址阻止。浏览器验证三格式 URL 导入、原预览、过期重新导入、错误提示与本地上传恢复；截图在 `test-results/url-import`。

独立产物验证：仓库外临时目录安装仅有 playwright-core 的锁定运行时依赖，启动 Node，提供静态前端并运行原 PPT 排版 Worker；再从浏览器执行三种格式及 HTML altChunk 的同一组回归。

媒体专项回归已验证：嵌入的真实 VP8 视频与 PCM 音频在普通预览中成功解码，播放时间推进；服务端 Range 返回原始媒体字节；关闭/翻页后原播放器暂停；放映中的视频播放；损坏媒体明确报错。

这些检查证明应用可运行和核心实现沿用，不等同于复杂文档的完整视觉一致性验收。

## 尚未验收/尚未完成

初次审查列出的首期实际功能缺口现已接入，修复与验证对照见 [功能审查](FEATURE_AUDIT.zh-CN.md)。仍需在固定原 Electron/浏览器/字体环境下逐页对照：目前的源码一致性、稳定分页、浏览器功能回归和截图检查不能证明所有复杂文档视觉一致。
