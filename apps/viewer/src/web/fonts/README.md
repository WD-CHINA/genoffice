# Viewer PPT fonts

The catalog is generated by `tools/build-viewer-font-catalog.py` from the
migrated Word `fonts.css`, `fonts.generated.css` and font-metrics manifests.
It includes all 66 migrated source files and six new symbol stand-ins:
651 portable face declarations across 76 CSS families. Range-dependent size
adjustments, ascent/descent/line-gap overrides and Office aliases accompany
the same font bytes in both worker layout and browser drawing. Local-only
system font declarations are not advertised as bundled fonts.

`catalog.json` records source paths and descriptors for auditing. The TypeScript
catalog resolves asset URLs through Vite. `metrics/` contains WOFF2 coverage,
advances and vertical metrics, generated from the original files with source
SHA-256 hashes. These avoid a Node/Brotli dependency in browser workers.
Browser width feedback supplies shaped/kerning widths, including Arabic and
Indic scripts; sidecar advances are initial estimates for those scripts.

Font bytes are parsed once per source, range faces retain CSS cascade order,
and browser faces load only for requested measurement families. The document
scope removes its faces and aliases on close. Embedded fonts override bundled
aliases. Missing fonts/glyphs retain the fallback path; e.g. Palatino Linotype
is still a serif substitute, not a bundled original.

## Symbols

`tools/build-viewer-symbol-fonts.py` builds monochrome outlines from pinned
Noto Sans Symbols 2, Noto Sans Symbols, Noto Sans Math, Noto Emoji and Noto Sans
sources. `symbol-sources.json` records download URLs and SHA-256 hashes; place
these files in a directory and pass that directory to the script. Original
copyright notices and SIL OFL licenses are retained in `LICENSE-*.txt` and
copied into Viewer release packages.

The stand-ins cover every entry in the existing engine maps:
Symbol 189, Wingdings 221, Wingdings 2 216, Wingdings 3 207, Webdings 222.
`symbol-coverage.json` records the generated coverage. Raw bytes and U+F0xx
share glyphs for the dingbat fonts. Symbol provides Unicode plus U+F0xx,
matching the render layer's existing Adobe Symbol decoding. The additional
Unicode symbol face covers mathematical and standard symbol fallbacks.

These reproduce the engine's Unicode equivalents and approximations rather
than proprietary Wingdings outlines. Coverage is complete for those maps,
not for every undocumented legacy-font code. Original PPTX text is retained.

## Validation

`pnpm --filter @genoffice/viewer test` validates source coverage, symbol cmaps,
WOFF2 hashes, aliases, script fallback, range metrics and face ownership.
With a running Viewer dev server, `pnpm --filter @genoffice/viewer test:pptx-fonts`
checks actual Chrome fonts and widths plus a simulated HTTP server-model worker.
Set `VIEWER_FONT_URL` and `VIEWER_FONT_OUTPUT` to override its default local URL
and artifact directory. The backend transport is simulated; parsing, font
files, layout and browser measurements use real code and data.
